# Project Figures

This directory contains visualizations summarizing the experiment results and architecture.

- **experiment_macro_f1.png**: Shows Test Macro F1 across B0-B3 based on the consolidated JSON.
- **validation_vs_test_macro_f1.png**: Compares best validation vs test Macro F1 across B0-B3.
- **per_class_f1_comparison.png**: Displays the breakdown of F1 scores per class for B0-B3.
- **b1_confusion_matrix.png**: Confusion matrix extracted from B1's official test evaluation output.
- **dataset_class_distribution.png**: Training, validation, and test sample counts per class.
- **cnn_architecture.png**: Flow diagram representing the 93,575-parameter LightweightCNN structure.
